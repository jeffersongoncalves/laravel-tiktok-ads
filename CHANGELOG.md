# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-09-08

First release.

- TikTok Business API v1.3 client on top of Laravel's HTTP client
- Advertiser info, campaigns (list/create/status update), ad groups, integrated reports, custom audiences
- Config with TIKTOK_ACCESS_TOKEN, TIKTOK_ADVERTISER_ID and TIKTOK_ADS_API_VERSION
- Facade and container binding, PHP 8.2+, Laravel 12/13
